Honest Technical Scope & Limitations

Our current security and reliability projects are prototypes and targeted developer tools—not a certified anti-cheat product, a complete penetration test, or a guarantee against payment loss. File hashing verifies file contents against a supplied expected hash; it does not by itself detect every form of runtime tampering. Webhook fixes must be tested against the customer’s actual application and database.
